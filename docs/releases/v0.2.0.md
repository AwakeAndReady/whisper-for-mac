Whisper for Mac 0.2.0 makes repeated transcriptions easier and adds a sequential
queue for working through multiple recordings. Audio processing remains local
on your Mac.

## Quick Start and remembered settings

- Select a recording and review the model, spoken language, task, output formats,
  and output folder in the new Quick Start summary.
- The model, language, and task from the last started transcription are remembered
  across app restarts. Output formats, output location, and the Core ML preference
  also keep their saved settings.
- Use **Change Settings** to return to the setup wizard. A transcription starts
  only when you explicitly click **Start Transcription** or **Start Queue**.

## Multiple-file queue

- Select multiple audio or video files in Finder, or drag them into the app.
- Review the list, remove files, and add more recordings before starting.
- The queue processes recordings one at a time using shared settings and continues
  after an individual file fails.
- Results show the status of each recording, with Open, Reveal in Finder, and
  Copy actions for completed files.
- **Stop Queue** cancels the current recording and skips waiting files while
  keeping completed results. **Retry Failed** and **Retry Unfinished** retry only
  the files that still need processing.
- Source-folder output now correctly follows each input file even when a custom
  output folder was previously saved.

## Completion and cancellation

- Receive a macOS notification when a transcription or queue finishes while the
  app is in the background, after allowing notifications. A queue sends one
  summary notification rather than a notification for every file.
- Finder opens automatically only if you enable this in **Settings > Output >
  When Finished**. Automatic reveal is off by default; manual reveal remains
  available on the results screen.
- Copy the complete transcript using the discreet copy icon beside the output
  files, including when only subtitle formats were exported.
- Cancellation has its own neutral result state, with options to restart with
  the same file and settings or choose another file. The app first shows
  **Cancelling transcription** until the active work has stopped. Cancelled jobs
  do not send completion notifications.

## SRT subtitles

- Export **SRT** alongside **TXT** and **VTT**, individually or in combination.
- SRT files use numbered cues and comma-separated millisecond timestamps.
- Output files retain the existing collision protection: a new transcription
  selects a new filename instead of overwriting earlier outputs.

## Download and installation

Download **WhisperForMac-v0.2.0-macOS-universal.zip**. It contains a single folder
with the app, installation instructions, and license notices.

- Requires **macOS 15 or newer**, on Apple Silicon or Intel.
- Quit the previous app before replacing it. Follow **README.txt** in the download.
- This release is **not signed with an Apple Developer ID or notarized by Apple**.
  If macOS blocks the first launch, follow the Open Anyway instructions in
  README.txt, and proceed only if you trust this download source.
- No Whisper model is bundled. Download a model in Settings before transcribing.
  Model downloads require an internet connection; transcription itself runs offline.

## Current limits

- The file queue is kept only for the current app session and is not restored
  after quitting.
- Speaker identification is not included in this release.
- Very long recordings and long-running cancellation still need broader real-world
  validation; passing automated tests does not establish reliability for every recording.
