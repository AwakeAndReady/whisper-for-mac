Whisper for Mac - Installation
==============================

Official download:
https://github.com/AwakeAndReady/whisper-for-mac/releases/latest

Requires macOS 15 or newer on an Apple Silicon or Intel Mac.

1. Quit any copy of Whisper for Mac that is already running.
2. Unzip the download and open the folder it creates. Move
   WhisperForMac.app from that folder to Applications.
3. Open WhisperForMac.app from Applications.

If macOS says Apple cannot verify the app for malware:

4. Click Done ("Fertig"), not Move to Trash.
5. Open System Settings > Privacy & Security
   ("Systemeinstellungen" > "Datenschutz & Sicherheit").
6. Scroll down to Security and click Open Anyway ("Dennoch öffnen")
   for WhisperForMac.app, then confirm Open ("Öffnen").

This release is not signed with an Apple Developer ID or notarized by Apple.
Only override the warning if you trust the download source. A newly
downloaded version may need the same approval again. You do not need to
disable macOS security.

Apple's instructions:
https://support.apple.com/de-de/102445

After opening the app, use Settings to download a Whisper model. No model
is included in the app download.
